олон хэрэглэгчийн зэрэгцээ хүсэлт, accessibility-г хамруулах charter боловсруулах шаардлагатай, учир нь эдгээр чиглэл бүрэн шалгагдаагүй үлдсэн. 
Автоматжуулалтын хувьд Playwright-ийн DOM assertion нь тоолуур, validation, давхардал, хайлт, эвдэрсэн линк, буруу мессеж, урт оролтын хэмжээний алдааг барьж чадна.
Харин HTTP түвшний автомат тест нь malformed JSON, `null` хүсэлтээс үүдэх crash болон буруу status code-ыг илрүүлнэ. Ногоон устгах товч, латин `x`, таслалтай он, 
хүснэгтийн харааны эвдрэл зэргийг хүний нүд эсвэл visual regression тестээр шалгах нь илүү тохирсон гэж үзэж байна.
